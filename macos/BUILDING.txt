清幽私人云 macOS 客户端 1.0.0

组成
----
界面：Swift / SwiftUI（macOS 13+），源码在 macos/app，用 Swift Package Manager 构建，
      不需要 .xcodeproj，也不需要 Xcode 图形界面。
内核：Go 1.21+（开发机用 Go 1.27.3 验证），源码在 macos/engine，零第三方依赖
      （MD4/DES/MSCHAPv2 自实现，只用标准库），因此可以离线构建。
打包：macos/build.sh 一次完成内核交叉编译、lipo 通用二进制、Swift release 构建、
      .app 组装、ad-hoc 签名、zip 打包。

构建
----
  cd macos
  ./build.sh              # arm64 + x86_64 通用版本，产物在 macos/dist
  ./build.sh --arm64      # 只构建 Apple Silicon
  QYVPN_VERSION=1.0.1 QYVPN_BUILD=2 ./build.sh

客户端令牌的注入方式：build.sh 读取 QYVPN_API_TOKEN，或仓库根目录的
.private/client.properties 里的 apiToken=，通过
  -ldflags "-X qingyou/qyvpn/internal/cloud.DefaultToken=<token>"
写进内核二进制（与 Windows 版随包内置令牌的做法一致）。令牌只有配置读取、
状态读取、客户端统计上报权限，不含后台管理权限。
没有令牌也能构建，但客户端无法同步节点。

后台的 macOS 通道（2026-11-09 已补齐）
-----------------------------------
后台 1.6.49 新增了 macOS 发布通道，客户端 /api/app/macos-release 的检查与下载现在有接口可用：
  - 后台上传：管理后台「macOS 客户端 → 发布 macOS 版本」，选 build.sh 产出的 zip（上限 200 MB）。
    后台自动从 .app/Contents/Info.plist 读版本号，校验 Bundle ID（cn.qo8.qyvpn.client）、
    可执行文件与内嵌 qyvpn-engine（必须是 Mach-O），并要求版本号高于历史发布版本。
  - 客户端检查：GET /api/app/macos-release → {release:{version,notes,sha256,size,published}}；
    有新版本时客户端下载 /api/app/macos/<sha256>，校验大小与 SHA256 后存到
    ~/Library/Application Support/QingyouPrivateCloud/updates/，并在 Finder 里定位，
    安装仍需用户把 .app 拖进「应用程序」（macOS 不能原地替换运行中的程序）。
  - 公开下载：/download/macos 优先返回正式发布的安装包（文件名带版本号）；
    没发布过时回落到 <data>/macos-releases 下最新的 zip/dmg，方便临时手工丢包。

协议要点（移植自 app/src/main/java/kittoku/osc，Android 端实跑验证过的实现）
--------------------------------------------------------------------------
- SSTP 头 4 字节：类型（0x1000 DATA / 0x1001 CONTROL）+ 总长度；DATA 帧后接
  0xFF03 + PPP 协议号。
- 控制包 8 字节头：类型、长度、消息类型、属性数量；属性 4 字节头：保留、ID、长度。
- CALL_CONNECTED 必须是 112 字节：属性值 = 3 字节保留 + 哈希算法 + 32 nonce +
  32 证书哈希 + 32 CMAC；CMAC 用 HLAK→CMK 两段 HMAC 计算，包内 CMAC 位置先置零。
- PPP 长度字段 = 4 + 数据长度（从 Code 起算，不含协议号）。
- 认证：LCP 里按服务器要求选 PAP / CHAP-MSCHAPv2 / EAP-MSCHAPv2；当前线上节点是 PAP，
  PAP 没有 MSK，SSTP 绑定按协议用全零 HLAK。
- IPCP：请求 IP 与 DNS，服务器 NAK 后取回分配值；对端请求里的 DNS 选项一律 Reject。

安全与数据
----------
- 本地通信令牌 32 字节随机值，界面 0600 保存，内核侧 /Library/Application Support 0600；
  socket 0666 但每个请求校验令牌。
- 连接日志写在 /Library/Application Support/QingyouPrivateCloud/connection.log，
  约 1 MiB 轮转，password/token/authorization 全部脱敏。
- 统计上报使用随机生成的设备键（同一台机器固定），不采集硬件信息。
- 客户端不修改系统 VPN 配置、不装第三方网络驱动；只建 utun、加路由、写 DNS 状态。
